# Staff dashboard guide (demonstration)

Open `admin.html` in the browser. There is no login in this demonstration. The notice across the top explains this is not secure or connected to an official site.

- **Overview:** counts and quick actions.
- **School pages:** try editing the introductory copy. It appears locally as a preview banner.
- **Notices:** create or edit a notice; save it as a draft or publish in the local preview; pin/unpin, unpublish or delete it. The PDF picker reads a small file into this browser only.
- **Teaching staff:** add, edit or remove sample directory entries. Names/images must be authorised before real use.
- **Photo albums:** add a captioned sample image. Files stay in local storage in this browser.
- **Documents:** add and replace sample PDFs/links.
- **Settings & records:** export/import demo JSON or reset sample data. A JSON export is not encrypted and is not a secure backup.

The browser's local storage is separate on each browser/device, may be cleared, has limited capacity and can be read by scripts running on the same origin. Do not use this preview for credentials, student information or confidential school records. No edit in this panel changes the actual GitHub repository or school website.
